# Fotografías ilustrativas del catálogo demo

Copias iniciales empaquetadas para funcionar sin conexión, procedentes de las
URLs que ya utilizaba el catálogo de Champ. No representan fichas de perros
reales disponibles para cruces.

- Luna: https://images.unsplash.com/photo-1552053831-71594a27632d
- Max: https://images.unsplash.com/photo-1633722715463-d30f4f325e24

Se solicitan como JPEG de 700 px, calidad 75. Al inicializar la app se copian al
almacenamiento persistente y SQLite conserva su referencia por SHA-256. La URL
original queda como atribución de procedencia, no como dependencia de ejecución.
